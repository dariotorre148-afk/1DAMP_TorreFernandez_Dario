# Introducción al software

## ¿Qué es un programa informático?

Un programa informático es un conjunto de instrucciones escritas para que un ordenador realice una determinada tarea.

## Diferencia entre código fuente, código objeto y código ejecutable

### Código fuente

El código fuente es el conjunto de instrucciones escritas por el programador utilizando un lenguaje de programación.

### Código objeto

El código objeto es el resultado de traducir o compilar el código fuente a un formato más cercano al lenguaje máquina.

### Código ejecutable

El código ejecutable es el programa preparado para poder ser ejecutado por el sistema.

## Etapas del desarrollo del software

1. Análisis de requisitos.
2. Diseño.
3. Codificación.
4. Pruebas.
5. Despliegue.
6. Mantenimiento.
